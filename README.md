## ✨ Что сделано

- 🧭 **Шапка** — логотип (свой из админки или название сайта), меню, на телефоне бургер с `aria-expanded`, закрытием по Esc и по клику на ссылку
- 🚀 **Главный экран** — заголовок, подзаголовок, одна заметная кнопка, Отто (SVG-заглушка)
- 🃏 **Преимущества** — три карточки
- 💬 **Отзывы** — три карточки
- 🦶 **Подвал** — текст, меню, ссылка на политику конфиденциальности (появляется сама, если страница назначена в Настройках)
- 🍪 **Баннер cookie**, **страница 404**, **мета-теги** (description, keywords, Open Graph, Twitter Card), фавикон по умолчанию
- ♿ Skip-link, контраст текста по WCAG AA, `alt` у картинки, `prefers-reduced-motion`

Ничего не зашито в код: меню и все тексты правятся в админке.

## 🚀 Установка

**Вариант 1 — архивом.** Запакуйте папку темы и загрузите в WordPress: **Внешний вид → Темы → Добавить → Загрузить тему**, затем **Активировать**.

```powershell
Compress-Archive -Path codepath-theme -DestinationPath codepath-theme.zip
```

**Вариант 2 — через git.**

```bash
cd wp-content/themes
git clone https://github.com/Tonxetyz/codepath-theme.git
```

После активации:

1. **Внешний вид → Меню**: создайте меню и назначьте его на «Основное меню (шапка)» и «Меню в подвале». Пока меню не назначено, показываются ссылки по умолчанию.
2. **Настройки → Конфиденциальность**: выберите страницу политики, ссылка появится в подвале.
3. Создайте страницу «Условия использования» и добавьте её в меню подвала.
4. Для лендинга на главной подойдёт любая настройка «Главная страница»: `front-page.php` используется всегда.

## ✏️ Как редактировать

| Что | Где |
|---|---|
| Меню шапки и подвала | Внешний вид → Меню |
| Заголовок, текст и ссылка кнопки | Внешний вид → Настроить → Главный экран |
| Карточки преимуществ | Настроить → Преимущества |
| Отзывы | Настроить → Отзывы |
| Текст подвала, баннер cookie, ключевые слова | Настроить → Подвал, cookie и SEO |
| Логотип, иконка сайта | Настроить → Свойства сайта |
| **Отто** | замените файл `assets/otto.svg` (для PNG/WebP поправьте имя в `template-parts/hero.php`) |

> ⚠️ Тексты отзывов по умолчанию — **примеры**. Замените их настоящими, прежде чем публиковать сайт.

## 🧪 Что проверялось вручную

Проверка шла на лёгком стенде: PHP 8.4 (CLI) с набором заглушек функций WordPress, в браузере Claude.

- ✅ `php -l` для всех 10 PHP-файлов: ошибок синтаксиса нет
- ✅ Телефон (375×812): нет горизонтальной прокрутки (`scrollWidth` = 375, ни один элемент не выходит за край)
- ✅ Консоль браузера: ошибок и предупреждений нет
- ✅ Бургер-меню: открывается, `aria-expanded` меняется, клик по ссылке закрывает меню и прокручивает к секции
- ✅ Баннер cookie: показывается, после «Понятно» не возвращается после перезагрузки
- ✅ Десктоп (1280×800): две колонки в герое, три карточки в ряд
- ✅ `<head>`: description, keywords, Open Graph, Twitter Card, фавикон
- ✅ Страница 404 отдаёт статус 404
- ✅ Работа без плагинов: тема использует только функции ядра WordPress (поиск по коду не нашёл вызовов плагинов)

## 🐞 Что нашёл и исправил

Все правки в [PR №6](https://github.com/Tonxetyz/codepath-theme/pull/6).

1. **Баннер cookie занимал около трети экрана телефона.** Уменьшил отступы, кнопка теперь в одной строке с текстом (высота 128 px вместо ~170).
2. **Липкая шапка уходила под админ-панель WordPress** у залогиненных. Добавил отступ для `.admin-bar` (32 px; 46 px на планшетах; 0 на узких экранах, где панель уезжает при прокрутке).
3. **Отступ при переходе по якорю** был 80 px при шапке 64 px, теперь 64 px.

## ⚠️ Что не проверено и ограничения

- **Настоящий WordPress не запускался**: на стенде его функции заменены заглушками. Админка, Настройщик и вывод `wp_nav_menu` реальным меню проверены только чтением кода. Проверьте тему на тестовом сайте.
- Не сделано, так как на лендинге это не нужно: формы (валидация, капча), слот под аналитику, WebP/AVIF (в теме нет растровых картинок, только SVG). Аналитику можно добавить через `wp_head`/`wp_footer`.
- `sitemap.xml` и `robots.txt` создаёт само ядро WordPress (`/wp-sitemap.xml`, `/robots.txt`).
- Иконки сайта во всех форматах WordPress делает сам из картинки, загруженной в «Свойства сайта»; до этого используется `assets/favicon.svg`.
- Мета-теги темы могут дублироваться, если установлен SEO-плагин; в таком случае отключите их в плагине или удалите блок в `functions.php`.

## 📁 Структура

```
codepath-theme/
├── style.css            # шапка темы + все стили
├── functions.php        # меню, скрипты, фавикон, мета-теги
├── header.php           # шапка сайта
├── footer.php           # подвал и баннер cookie
├── front-page.php       # лендинг: собирает блоки
├── index.php            # запасной шаблон (страницы, записи)
├── 404.php              # страница ошибки
├── inc/customizer.php   # тексты по умолчанию и поля Настройщика
├── template-parts/      # hero, benefits, reviews
└── assets/              # otto.svg, favicon.svg, site.js
```
